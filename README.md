A two-part micro-confession — a `To:` line and the one unsent line itself, exactly as it was typed — written to `entry.txt` for make.fun's "Unsent: The Micro-Confession Sprint" bounty. Python 3.13 standard library only, deterministic: the same bytes every run.

## Run it

```sh
python3 main.py
```

Writes to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
